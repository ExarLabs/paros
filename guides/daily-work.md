# Working with PAROS day to day

## The rhythm

- **Start of a session:** the agent reads the vault entry file and your task list. You say what you want; you do not need to know which agent or skill handles it.
- **During work:** correct the agent whenever it is wrong. Each correction is a lesson (P05); you do not need to file it anywhere.
- **End of a session:** nothing special. Logs, learning and checks run on their own.

## Habits that pay off

- **Drop things into the inbox of your task list,** unformatted, even one word. The agent sorts them later.
- **Say "why" when you correct.** "Shorter" teaches less than "shorter, because this goes to a phone screen".
- **Let the agent name sessions** with machine, area and topic, so you find them later.
- **Ask for evidence.** "Did it work?" should be answered with the output, not with "the script ran" (P11).
- **Archive, do not delete** (P09).

## What you will see

- A one-line report when the system learned something: "Learned: … → file". Say "undo" if it was wrong.
- Marks like `[L-0123]` when a decision depended on a learned rule, so you can see whether past lessons help.
- A short cycle report from time to time: how much the system knows, what got stronger, what is under review.
- An alert line in your task list only when a health check changes from green to red.

## What never happens without you

Sending, publishing, deleting, money, credentials, writing into shared systems (P00).
