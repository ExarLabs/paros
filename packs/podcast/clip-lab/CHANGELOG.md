# Changelog: podcast-clip-lab

Every entry: what changed, and **what to review in a vault that has already adopted this skill.**

## 1.0.0 (2026-10-05)

- First public version, part of the podcast pack. A private clip page with cards, waveforms, drag-and-drop order, word-boundary nudging and an editor export; selection by the strongest model, anchors from the same word-level transcript, windowed end anchors.
- Recipe and spice: everything that belongs to one show lives in `LOCAL.md`, copied from `LOCAL.example.md` (a made-up show).
- Pitfalls R-001 to R-011. R-003 (four-second padding) is low evidence.
- To review: set your hosting route, URL pattern and shared file versions in `LOCAL.md`; build the first page locally before deploying.
