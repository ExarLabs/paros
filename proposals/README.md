# Proposals

Most suggestions reach the maintainers through the advisor's built-in feedback (sent through ignis.academy into the maintainers' CRM, no account needed); the maintainers copy accepted ones here. Suggestions from GitHub users arrive here as pull requests: each one adds a single file `proposals/YYYY-MM-DD-<slug>.md` on a branch of the sender's own fork. The maintainers read it, and if it helps, turn it into a real change (a playbook, a principle, a fix) in a separate commit. The proposal file itself is kept as the record of where the idea came from.

How proposals are made: [`tools/feedback.py`](../tools/feedback.py) and the "Feedback to the PAROS Advisor" section of [`AGENTS.md`](../AGENTS.md). You can also open an issue or a pull request by hand.
