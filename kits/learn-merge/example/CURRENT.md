# Meeting notes skill

## Constitution

The owner's fixed rules. Learning never changes this section; only the owner edits it by hand.

- Never send, publish or share the notes without the owner's explicit yes.
- Keep the raw transcript; the notes are derived from it, never the other way round.

## Rules

- Put decisions in their own list at the top, before the discussion summary. <!-- rule:R-001 since:2026-10-01 -->
- Write every action item as "owner: task, due date"; mark a missing due date as "no date". <!-- rule:R-002 since:2026-10-01 -->

## Heuristics

Softer guidance. New rules land here with `learn_merge.py add --section "Heuristics"`.
