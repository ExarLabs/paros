# Session naming

Every session is titled:

```
<MACHINE> <AREA> · <topic>
```

At most about 40 characters. The middle dot has a space on each side. The topic starts with the thing itself (client, product, document), in my language.

## Machine codes

| Code | Where the session runs |
|---|---|
| `WIN` | <my Windows computer> |
| `MAC` | <my Mac> |
| `WEB` | browser or cloud session |
| `MOB` | started from my phone |

## Area codes

| Code | Area |
|---|---|
| `<ABC>` | <area 1, as named in my vault> |
| `<DEF>` | <area 2> |
| `SYS` | my notes system itself (agents, skills, settings) |

## Examples

- `WIN <ABC> · <topic from my life>`
- `MAC <DEF> · <topic>`
- `WEB SYS · <topic>`

## When to rename

The agent sets the title before its first real answer, as soon as the topic is clear, and updates it when the topic changes substantially. If the app does not let the agent rename the session, it suggests the title once, in one line, and I rename it.
