# Changelog: cv-tailoring

Every entry: what changed, and **what to review in a vault that has already adopted this skill.**

## 1.0.0 (2026-10-05)

- First public version, generalised from a bid-profile skill in daily use since September 2026 and distilled from two hand-made runs. A ten-step procedure: save the request verbatim with numbered requirements, find the freshest source CV, make a v0 copy, read the candidate's facts, map every requirement to evidence, write a tailoring plan with checked anchors, apply it into a new version, build an internal coverage table, draft an internal covering note, close.
- Constitution: the CV states only proven content; the framing rules (what is allowed, what is never allowed) are part of the constitution; the source CV is never changed; no compensation anywhere; anonymisation kept; nothing is sent.
- Pitfalls R-001 to R-007, including the byte-level reproduction test for an automated apply step.
- `LOCAL.example.md` for the personal setup (CV library locations, house format, anonymisation, folders, language of the note); a golden example with an invented candidate and an invented job.
- To review: copy `LOCAL.example.md` to `LOCAL.md` and fill in where your CVs live and how your house format looks; decide whether you want the framing rules exactly as written (they are constitution, so only you change them); make sure your people notes keep compensation in a section the skill can skip.
