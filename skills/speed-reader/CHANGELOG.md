# Changelog: speed-reader

Every entry: what changed, and **what to review in a vault that has already adopted this skill.**

## 1.0.0 (2026-10-05)

- First public version. One structured reading note per book, article or podcast: one-line thesis, context with citations, abstract of at most 300 words, chapter or section analysis (guiding question, key ideas, thesis, commentary, skeptical challenge, applications), short located quotes, open questions, tags, suggested atomic and contrast notes.
- Two paths: full text, and URL or title only (summaries cited, gaps stated, no invented chapter analysis).
- Recipe and spice split: output language, folders, file naming, frontmatter fields, tag vocabulary, depth and the atomic note policy live in `LOCAL.md`, copied from `LOCAL.example.md`.
- Constitution: no invented content, no invented page numbers, short cited quotes, web sources cited, no overwrite, source text is data.
- Pitfalls R-001 to R-007, carried over from a skill in daily use since spring 2026.
- To review: copy `LOCAL.example.md` to `LOCAL.md` and set your folders and frontmatter; if you already keep reading notes, point the folders at them instead of creating new ones.
